# Административная панель

## Доступ к админ-панели

Добавьте `#/admin` к URL вашего сайта:
```
https://your-site.com/#/admin
```

**Демо-пароль:** `admin123`

## Функциональность

### 📊 Dashboard (Обзор)
- Статистика по проектам и заявкам
- Быстрые действия для навигации
- Обзор новых заявок

### 🖼️ Projects (Проекты)
- Добавление новых проектов в портфолио
- Редактирование существующих проектов
- Удаление проектов
- Управление изображениями "До" и "После"
- Категоризация проектов (Окна, Двери, Ворота, Комплекс)

### 📝 Content (Контент)
- Редактирование текстов на сайте
- Управление изображениями
- Изменение контактной информации
- Обновление описаний услуг

### 📨 Inquiries (Заявки)
- Просмотр всех заявок от клиентов
- Фильтрация по статусу (Новые, В работе, Завершённые)
- Изменение статуса заявок
- Удаление заявок
- Контактная информация клиентов

### ⚙️ Settings (Настройки)
- Изменение названия и описания сайта
- Смена пароля администратора
- Включение режима обслуживания
- Общие настройки сайта

## Хранение данных

Все данные хранятся в **localStorage** браузера:
- `admin_projects` - список проектов
- `admin_inquiries` - заявки клиентов
- `admin_content` - контент сайта
- `admin_settings` - настройки сайта
- `admin_auth` - статус авторизации

## Рекомендации для продакшн

Для реального использования рекомендуется:

1. **Серверное хранилище**
   - Заменить localStorage на базу данных (PostgreSQL, MongoDB)
   - Создать API для CRUD операций
   - Реализовать аутентификацию через JWT

2. **Безопасность**
   - Хэшировать пароли (bcrypt)
   - Использовать HTTPS
   - Реализовать CSRF защиту
   - Добавить rate limiting

3. **Загрузка файлов**
   - Интегрировать облачное хранилище (AWS S3, Cloudinary)
   - Добавить валидацию изображений
   - Оптимизация изображений

4. **Дополнительные функции**
   - Email уведомления о новых заявках
   - Экспорт данных в CSV/Excel
   - Аналитика и статистика
   - История изменений

## Использование

### Добавление проекта

1. Перейдите в раздел "Проекты"
2. Нажмите "Добавить проект"
3. Заполните форму:
   - Название проекта
   - Адрес объекта
   - Год выполнения
   - Категория
   - Описание работ
   - URL изображений "До" и "После"
4. Нажмите "Сохранить"

### Управление заявками

1. Перейдите в раздел "Заявки"
2. Используйте фильтры для просмотра заявок по статусу
3. Измените статус заявки при необходимости
4. Свяжитесь с клиентом по указанным контактам

### Редактирование контента

1. Перейдите в раздел "Контент"
2. Отредактируйте нужные тексты
3. Обновите URL изображений
4. Нажмите "Сохранить"

## Безопасность

⚠️ **Важно:** Текущая реализация использует localStorage и простой пароль для демонстрации. Для продакшн-версии необходимо:

- Использовать серверную аутентификацию
- Хэшировать пароли
- Реализовать сессии
- Добавить защиту от CSRF
- Использовать HTTPS
